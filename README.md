# Health Vision 🌿

A simple healthcare website built using HTML, CSS, and JavaScript.

## 🔹 Description

Health Vision is a basic web project designed to help users navigate a health-related platform.  
It includes a home page, sign up page, and sign in page with simple form validation.

## 🔹 Features

- Clean user interface  
- Responsive layout  
- Sign Up & Sign In pages  
- Email and password validation  
- Easy navigation  

## 🔹 Pages

- Home Page (index.html)  
- Sign Up Page (signup.html)  
- Sign In Page (signin.html)  

## 🔹 Technologies Used

- HTML  
- CSS  
- JavaScript  
- Bootstrap (for responsiveness)  

## 🔹 How to Use

1. Download or clone the repository  
2. Open `index.html` in your browser
